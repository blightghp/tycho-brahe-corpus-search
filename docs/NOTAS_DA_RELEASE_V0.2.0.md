# Tycho Brahe Search v0.2.0 — prévia técnica Windows

Esta release substitui o instalador técnico anterior por um pacote NSIS
`v0.2.0` para Windows x64. Ela é uma **prévia técnica do cliente desktop**, não
uma distribuição científica estável do corpus.

## Incluído

- Interface redesenhada a partir da linguagem visual do portal Tycho Brahe:
  azul institucional, superfícies claras, tipografia editorial e navegação de
  pesquisa.
- Ícone fornecido para esta atualização, aplicado ao aplicativo e ao
  instalador.
- Rota M4/M5 com sidecar dedicado, contrato de evidências e localização
  controlada do artefato M3.
- Página obrigatória de aceite no instalador, com créditos e vínculo explícito
  aos [termos oficiais do corpus](https://www.tycho.iel.unicamp.br/corpus/termos.html).
- Checksum SHA-256 do instalador como arquivo anexo à release.

## Importante

O instalador **não contém** o Corpus Histórico do Português Tycho Brahe, fontes
PSD, M2, M3, credenciais ou dados derivados. Ele não concede acesso, licença
ou autorização para copiar ou redistribuir qualquer dado do corpus. Todo uso
de dados obtidos separadamente deve observar os
[termos oficiais](https://www.tycho.iel.unicamp.br/corpus/termos.html).

Esta prévia não certifica uma transdução cartográfica integral, não substitui
revisão humana e ainda não possui assinatura de código. Os pacotes `v1.0.0`
permanecem arquivados e não devem ser utilizados.

Os resultados de M3, M4, M5, build, testes e auditoria estão em
[VALIDACAO_M3_M4_M5_2026-09-04.md](VALIDACAO_M3_M4_M5_2026-09-04.md).
